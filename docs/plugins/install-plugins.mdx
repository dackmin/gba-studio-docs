# Plugins

GBA Studio allows you to extend its functionality through plugins (new event types, assets, custom
behavior, etc).

<img src="/images/plugin-manager.png" alt="Plugin Manager" height={200} className="rounded-xl" />

<br /><br />

:::tip
Plugins are project-bound, meaning they are only available within the project they are installed
in. To use a plugin in another project, you will need to install it separately for that project.
:::

## Install Plugins

- Go to the `View` menu, then open `Plugin Manager`
- Click on `Install plugin`
- Select the plugin's zip file or folder (the one containing a `plugin.json` file)
- Click `Open` to install the plugin

Congrats, it's installed and ready to use!

# Introduction

![GBA Studio](/images/screenshot-intro.png)

GBA Studio is a (quite) easy-to-use no-code game editor for the Game Boy ADVANCE.

It aims at being an unworthy sibling of [GB Studio](https://www.gbstudio.dev), so if you ever made a game
using GB Studio, everything should seem somehow familiar (just more clunky).

Create a game in minutes with zero knowledge and run it with any emulator, or
even flash the ROM into a cartridge.

<br /><br />

> Yes, it looks like XCode, because I loved the design when it first came out.
I honestly grew a bit tired of it, so if anybody has suggestions on how to improve the interface,
feel free to create an issue on [GitHub](https://github.com/dackmin/gba-studio/issues).
